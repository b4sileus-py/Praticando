# Praticando

Projetos pequenos, experimentos e testes de interface. Cada pasta é um projeto independente, que abre direto no navegador.

Aqui eu pratico usabilidade (heurísticas de Nielsen e Design Centrado no Usuário), acessibilidade e direção visual, com interfaces em português e dados sempre fictícios.

## Projetos

| Projeto | O que é | Tipo | Versão | Abrir |
|---|---|---|---|---|
| [Estante](estante/) | Registro pessoal de leituras: o que estou lendo, o que já li e o que quero ler, numa estante desenhada a partir dos próprios livros. | Sistema web, HTML único e offline | 0.1 | [Abrir no navegador](https://b4sileus-py.github.io/Praticando/estante/) |

## Como abrir um projeto

O jeito mais rápido é o link **Abrir no navegador** na tabela acima. Para usar no seu computador:

1. Baixe o repositório (**Code → Download ZIP**) ou clone com `git clone https://github.com/b4sileus-py/Praticando.git`.
2. Entre na pasta do projeto e abra o `index.html` no navegador.

Os projetos não precisam de instalação nem de internet, salvo quando o README do projeto disser o contrário.

## Como cada projeto é organizado

```
nome-do-projeto/
├── index.html        a aplicação
├── README.md         apresentação, como usar e decisões
├── design-notes.md   paleta, fontes e o que foi descartado
├── docs/             capturas de tela
└── testes/           testes automatizados, quando houver
```
